# Changelog

## 1.0.4

- Import multiple recipe files from one file-picker selection.
- Deduplicate both existing files and repeated content within a batch.
- Report imported, duplicate and failed counts; continue after an invalid file.
- Keep a per-recipe delete button with name confirmation.
- Publish a signing-neutral Xcode project and reproducible synthetic fixtures.

## 1.0.2–1.0.3

- Enable trial encoding for all six traditional base styles and automatic values.
- Reuse camera-native monochrome metadata and remove destination-shape blocking.
- Add deletion of local library copies.

## Earlier development

- Implement persistent Z30 PTP/IP sessions, C1–C9 writes, batch assignments and readback.
- Preserve complete custom curves and distinguish stored data from mode-1 state.
